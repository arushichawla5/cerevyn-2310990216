# Sample data

SYNTHETIC: generated by ndvi_monitor.data.make_sample(seed=42); not real imagery.

- `farm_two_dates.npz` - 20x20 arrays: red1, nir1, valid1, red2, nir2, valid2, farm.
- `expected_results.json` - output of the default configuration (checked by tests).

Built-in scenario: 240 farm pixels; date 1 has a 20-pixel cloud, one zero-denominator pixel (red = nir = 0); date 2 has a different 20-pixel cloud and a 6x6 patch (36 px) whose NDVI falls from about 0.70 to about 0.30. Hand-derived: usable on both dates = 240 - 20 - 20 - 1 = 199.
